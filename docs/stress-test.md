# 敌人与投射物压力场景

2026-09-23，Unity 6000.3.22f1。本次使用现有战斗代码做一轮负载探索，没有实施对象池或投射物重构。

## 运行入口

打开 `unity-game/Assets/Scenes/StressArena.unity` 并进入 Play Mode。场景中的原 `WaveSpawner` 组件已停用，同一物体上挂有 `TestEnemySpawner`；Player 上的 `TestShoot` 会自动寻找存活敌人并发射普通弹。

`Main Scenes.unity` 是原 `TestArena.unity` 的独立副本，目前内容相同。原 TestArena 未改动。压力场景以自己的玩家生命值和独立 `TestShootSkill` 资产调整负载。

| 设置 | 本次保存值 |
|---|---:|
| 总生成敌人数 | 45 |
| 敌人生成间隔 | 0.2 秒 |
| 自动射击冷却 | 0.1 秒 |
| 单发伤害 | 0.2 |
| 索敌半径 | 30 |
| 弹速 | 10 |
| 最大飞行距离 | 20 |
| 测试玩家生命 | 100000000 |

作者确认这套数值就是本次最高测试档位。总生成数不等于始终存活的敌人数；敌人可以受伤死亡。0.1 秒是配置的最小射击间隔，不是实测每秒必定发射 10 枚。生成和射击每次 Update 最多执行一次，受时间步与帧率影响，没有低帧率补发。有存活目标才发射，无目标时每帧重新查询。

动态敌人通过已有 `EnemyController.Initialize` 获得目标和场景网格；自动射击保留物理范围查询与最近目标筛选，再调用现有 `ArrowAction.Initialize`。因此本场景覆盖索敌、创建、飞行、碰撞和销毁，并非只测弹体移动。测试时保持玩家操作、窗口大小与诊断开关一致，才能比较前后。

刷怪达到总数后停止；自动射击没有独立持续时间或停止按钮。结束测试可退出 Play Mode，下次进入时重新从场景保存值开始。原有手动技能仍保留，记录测试时是否使用；本次未记录其完整操作轨迹。
